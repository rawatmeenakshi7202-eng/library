# 📚 Library Management System

A simple Library Management System built using **Python**, **Flask**, and **MySQL**. This project allows users to manage books, students, and book issue/return records through a web interface.

## 🚀 Features

- 📖 Add Books
- 🗑️ Delete Books
- 👨‍🎓 Add Students
- ❌ Delete Students
- 📚 Issue Books
- 🔄 Return Books
- 📋 View All Books
- 📋 View All Students
- 📋 View Issued Books

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/library.git
```

2. Open the project folder.

3. Install dependencies.

```bash
pip install flask mysql-connector-python
```

4. Import `library.sql` into MySQL.

5. Run the project.

```bash
python lib.py
```

6. Open your browser and visit:

```
http://127.0.0.1:5000
```
